A high-performance, responsive administration portal engineered for the **MARVELOUS-STORE** e-commerce ecosystem. This dashboard bridges the gap between raw database order history and customer-facing operations, allowing admins to instantly view transactions and generate high-fidelity, client-ready digital receipts.

---

## ✨ Key Features

* **Live Order Stream Sync:** Deeply integrated with production database routes to fetch real-time e-commerce transaction histories.
* **Smart Data Mapping & Fallbacks:** Built-in tolerance for multiple backend naming conventions (handles `totalPrice` vs `amount`, `customer_name` vs `user.name` perfectly).
* **High-Fidelity PDF Generation:** Single-click modern retail receipt engine powered by `jspdf` and `jspdf-autotable`, complete with dynamic tax calculations, custom subtotal cards, and structural table overflow defenses.
* **Unified Inventory Categories:** Pre-built interface architecture mapping directly to next-gen retail slots like **Smart Tech**, **Audio Gear**, **Computers**, and **Gaming**.
* **Premium UI/UX:** A midnight-themed UI constructed with React-Bootstrap, featuring dynamic state badges, clean loading animations, and robust error safety boundaries.

---

## 🛠️ Architecture & Tech Stack

* **Frontend:** React (Hooks, Context, Functional Components)
* **Styling & Theme:** React-Bootstrap / Bootstrap 5 (Dark Mode Layouts)
* **HTTP Client:** Axios (Asynchronous REST API Integration)
* **Document Compilation:** jsPDF & jsPDF-AutoTable
* **Target Environment:** Render API & Supabase/E-commerce backend matrix
